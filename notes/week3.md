# 第 3 周总结（W3）：委托事件 + 集合 + 动画 + UI + 整合

## 本周时间

D15–D21（9/19 – 10/14，中间有间隔）

## 本周产出

- **D15**：委托 delegate / 事件 event / Action / Func / `?.Invoke`，Unity 事件驱动（金币事件 + UI/音效订阅）
- **D16**：Lambda 四种形态 + List 全套（Add/Remove/Find/FindAll/Sort）+ 生成器模式（Instantiate→GetComponent→回填→登记）
- **D17**：Dictionary 增删查改 / TryGetValue + Animator 动画（Idle/Move/Jump）+ 静态配置表 + 命令模式雏形
- **D18**：UGUI 系统（Canvas / Button / Slider / Text / Panel）、场景切换、暂停（timeScale）
- **D19**：状态机完善（Lose）+ 主菜单设置 + PlayerPrefs 存档 + 血条事件驱动
- **D20**：W3 整合——敌人 AI 三态状态机（Patrol/Chase/Attack）+ 玩家 K 键攻击 + AudioManager 音效 + 随机生成 + 完整流程闭环
- **D21**：复盘——W3 速查表 + 3 道闭卷自测（事件系统 / 命令系统 / 集合查找排序）

## 核心成果

做出第一个**完整可玩小游戏 MiniLevel**：主菜单 → 关卡 → 吃金币/打怪/躲敌人 → 胜负结算 → 重开/回菜单。

- 敌人**有限状态机**：巡逻 / 追击 / 攻击按距离自动切换（W4 Demo1 的底稿）；
- 事件驱动 UI 和音效（核心逻辑不认识表现层）；
- 单例 AudioManager（6 音效 + 判空保护）、GameManager；
- 主菜单、设置、暂停、音量、最高分存档全部打通。

## 卡点与解决

| 卡点 | 解决 |
|------|------|
| 委托/事件初期理解困难 | 用"通知群"类比打通，订阅者只响应不干预 |
| 序列化坑：改代码默认值不生效 | 记住以 Inspector 为准，调数值在 Inspector |
| 音效空引用中断核心玩法 | 单例调用加 `?.`，附属功能不能阻断核心 |
| 类体里不能写执行语句 | 注册语句放构造函数，业务放方法 |
| timeScale 粘性、切场景不重置 | LoadScene 前拨 1 + Awake 保底 |
| 距离判断误用预制体、全局只算一次 | 距离写进 FindAll 的 lambda，对每个敌人现算 |

## 收获

1. 从"会写语法"跨到"能做完整游戏"，第一次独立把多个系统串成闭环；
2. 掌握了游戏开发核心模式：**事件驱动、有限状态机、集合管理、单例、生成器**；
3. 调试能力提升：能从"多个功能同时失效"反推共同原因（如空引用中断）；
4. 理解"核心玩法 / 附属表现"的健壮性边界。
